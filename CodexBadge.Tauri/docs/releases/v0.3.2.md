# Codex Badge v0.3.2

A lightweight Windows badge for Codex usage limits, reset times, and reset credits.

## What's new
- API-driven quota display: five-hour priority, weekly-only fallback; account changes and failed reads do not reuse another account's quota.
- Refined Glass/System themes, capsule contrast, compact hover panels, and reset-credit reminders. Weekly-only reset dates and credits share one bottom row; dates use M/D HH:mm.
- A themed, draggable update panel under Settings > Check for updates, with release notes and an update notification dot. Fixed disappearance while dragging and moved tray menus closer to the pointer.
- Manual one-click updates for installed copies, with signed update verification. Portable copies continue to update manually from the release page. No automatic checks/downloads/installation.
- Installer upgrade and same-version reinstall support, preserving settings.

## Download
- Installer: `Codex.Badge_0.3.2_x64-setup.exe`
- Portable: `CodexBadge-v0.3.2-windows-x64-portable.zip`
- Windows 10/11 x64; requires system WebView2, signed-in Codex desktop, and working Codex CLI. Interface: Chinese. Independent community project, not an official OpenAI product.
- Updater signatures do not replace Windows Authenticode signing; Windows may show an unsigned-app warning.

## Validation and known limits
133 Rust tests and 38 frontend/installer tests passed, plus signed-package tamper rejection. Weekly-only layouts were simulated across 3 themes and 100/125/150% scaling. Native isolated 125% checks verified dragging, Escape closing, and pointer-relative menu placement.
Real Pro reset/fireworks acceptance, native 100/150% and mixed-DPI dragging, and full install/upgrade/restart acceptance remain unverified. Weekly-only support and fireworks rules follow returned windows, not a hard-coded Plus/Pro assumption. Natural scheduled resets do not trigger fireworks.
