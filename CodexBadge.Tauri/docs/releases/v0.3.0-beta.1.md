# 余量 · Codex Badge v0.3.0-beta.1

Tauri 重构测试版，Windows 10/11 x64。保留旧 WPF v0.2.0 稳定版供回退；本版不是问题全部解决后的稳定替代品。本项目为第三方开源工具，与 OpenAI 无隶属关系，也未获得 OpenAI 背书。

## 更新内容

- Tauri 2 + Rust + 系统 WebView2 重构，不再需要 .NET Desktop Runtime。
- 通过本机 `codex app-server` 读取真实 5 小时/每周剩余额度、重置时间与重置机会；自动刷新，未知值不显示成零。不读取 `auth.json`、不调用内部 `wham` 接口。
- 只有两个可选主题：**毛玻璃风格 / 跟随系统明暗**。滚轮切换；默认毛玻璃风格，不宣称 Windows 原生亚克力。
- 已实现随 Codex 启停：打开后创建业务窗口并读取额度；退出后收起、停止我们启动的 app-server 并释放 WebView；保留轻量监听与托盘。重新打开后自动恢复。完整真实退出/重开验收仍待完成。
- 普通模式随 Codex 最小化隐藏；全局置顶模式在 Codex 最小化期间继续显示，且独立保存位置。Codex 真正退出后两种模式均收起。
- 两种模式均可右键胶囊。菜单优先于悬停详情；关闭菜单后移开再移入，才重新弹出详情。关闭置顶时检查 Codex 实时可见/最小化状态。
- 普通模式双击复位；置顶模式双击不复位。菜单保留开机启动、置顶模式、重新定位、退出。
- 详情保持现有右对齐和向左 2 DIP 留白，本版不追加胶囊移动、弹窗定位或底部间距调整。

## 下载与使用

- `CodexBadge-v0.3.0-beta.1-windows-x64-setup.exe`：NSIS 安装器。
- `CodexBadge-v0.3.0-beta.1-windows-x64-portable.zip`：便携包，解压后运行 `codex-badge-tauri.exe`。
- `SHA256SUMS.txt`：安装器与便携包的 SHA-256 校验。

需要 Microsoft Edge WebView2 Runtime、已登录的 Codex Windows 桌面客户端及可用的 Codex CLI。安装器可以引导下载 WebView2；便携版需自行确保该运行时已安装。本次不捆绑 Codex CLI 或完整离线 WebView2。本版未签名，Windows 可能显示未知发布者或 SmartScreen 提示。

若找不到 CLI，可将 `CODEX_BADGE_CLI` 设置为 `codex.exe` 的完整路径。软件监听程序须通过手动启动或开机启动保持运行，才会自动跟随 Codex；从托盘选择“退出”后不会自动跟随。

设置位于 `%LOCALAPPDATA%\CodexBadge\tauri-settings.json`，诊断日志位于同目录的 `tauri-diagnostics.log`。不自动导入旧版 `settings.json`。旧版和新版共享单实例限制，请先关闭旧版开机启动，再退出旧版，然后使用新版。回退时先关闭新版开机启动，再退出新版，然后运行旧稳定版；不要同时运行两者。

便携目录移动、便携版转安装版或卸载前，应先关闭本版开机启动；到新位置运行后，按需重新开启。开机启动记录的是当前程序的绝对路径。

## 已知问题与验收边界

- 快速来回悬停可能出现短暂花屏，根因尚未定位。
- 窗口最小化/还原、反复切换置顶与菜单、真实退出/重开后的 WebView2 和 app-server 资源释放，仍需完整桌面验收。
- 中文输入焦点问题、旧黑框/白边暂未复现，不代表所有 DPI 和多显示器场景均已解决。
- 普通模式弹窗仍跟随胶囊右边定位；手动移动胶囊可能使弹窗越出侧栏，但有屏幕工作区限制。当前胶囊可能未完全遮住官方“语音”文字，现有布局按原样保留。
- WebView2 多进程使活动内存高于旧 WPF 的短时参考值；不宣称低内存或长期性能已验收。
- 安装、升级、卸载、开机启动及 100/125/150/175% DPI、跨屏仍需更多实测。自动化测试和成功打包不能替代这些验收。
