# 余量 · Codex Badge v0.3.1

**适配新版 ChatGPT，修复胶囊定位。**

本次更新针对新版 ChatGPT Windows 客户端布局变化：旧侧栏定位锚点不再可靠，可能导致胶囊消失或位置不正确。更新客户端控件识别和缓存校验，适配新的布局，并保留旧版 Codex 客户端兼容路径。

## 修复与优化

- **胶囊定位**：普通模式胶囊贴合侧栏头像上方，统一居中与间距；置顶模式保留独立位置。
- **额度显示**：普通模式使用紧凑圆形数字，置顶胶囊保留小而细的百分号；统一个位、两位和三位数字的居中规则。
- **轻提示**：额度偏低、额度恢复及重置机会即将到期时在胶囊显示提示点；详情解释原因，读取失败时显示最近成功更新时间。Windows 系统通知可以独立关闭。
- **右键菜单**：胶囊与托盘使用相同菜单；“设置 ›”展开开机启动和系统通知，通知用途仅在悬停时显示。移除重新定位按钮，双击胶囊恢复默认位置。
- **绘制与交互**：主菜单、设置子菜单和用途说明先完整绘制后一次提交，圆角使用平滑透明边缘；修复小数缩放底边黑线、向左展开覆盖胶囊及旧鼠标坐标干扰。
- **详情面板**：删除重复倒计时文字，保留重置时刻；重置机会详情优先在额度面板上方展开，空间不足时放在下方。
