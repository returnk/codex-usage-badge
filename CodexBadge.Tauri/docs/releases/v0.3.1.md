# 余量 · Codex Badge v0.3.1

**适配新版 ChatGPT，修复胶囊定位。**

本次更新针对新版 ChatGPT Windows 客户端布局变化：旧侧栏定位锚点不再可靠，可能导致胶囊消失或位置不正确。更新客户端控件识别和缓存校验，适配新的布局，并保留旧版 Codex 客户端兼容路径。

## 修复与优化

- 适配新版 ChatGPT 侧栏布局，修复胶囊定位与数字居中，改善不同位数的显示。
- 优化额度面板的间距、圆角与交互；拉宽侧栏后保持默认左侧间距。
- 提示仅保留重置卡临近过期：48 小时内提示一次，24 小时内提示两次；系统通知可独立关闭。
- 收紧重置彩蛋的识别，结合重置卡变化、额度恢复和延迟确认，减少误触发。
