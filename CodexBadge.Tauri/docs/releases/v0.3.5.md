# Codex Badge v0.3.5

当前完整功能统一为本地 v0.3.5，尚未上传 GitHub。此前 0.3.6/0.3.7 仅为本地构建编号，历史包及记录保留，不作为当前交付。

- 改进额度恢复识别及服务数据分步更新、卡片明细不完整时的处理，补充经过脱敏的本地诊断，并限制额外补读次数。
- 修复官方更新控件处于下载、显示下载百分比或安装状态时，普通模式胶囊可能与其重叠的问题。
- 新增“临期用卡”：默认关闭，首次明确确认当前账号的持续授权；开启后，在免费卡到期前 30 分钟内符合条件时自动尝试，无需逐次确认。
- 使用具体卡 ID 和持久化幂等键，同账号本机互斥；原目标到期前不换下一张。超时有界核实，无法确认就暂停，避免重复用卡。
- 胶囊驻留且电脑正常运行时，无需打开 Codex 窗口；关机、休眠或退出后不执行。不擅自开启启动项，不安装服务或唤醒电脑。
- “临期用卡”采用右侧打勾，悬停可查看状态、最近结果和时间；暂时断网会暂停执行并保留关闭入口。开机启动和底部检查更新保留。
- 移除独立系统通知开关和旧临期 Windows 弹窗，保留胶囊红点和卡片到期信息。Windows 通知仅用于自动用卡成功或需要处理的失败结果；即使系统未显示，软件内仍能查看结果。

已有额度不与重置后的额度叠加，重置时间可能改变，成功不能撤销。满额、没有适用窗口或服务端拒绝时不强制用卡，不保证到期前兑换成功。同账号不要在多台设备或工具同时启用。

关闭阻止新请求，已发送的请求不承诺撤销。先前请求结果无法确认时保留未决记录并暂停，需要核查官方状态；切换开关不会清空该状态。旧 CLI 不支持时显示不可用，没有内部网页接口兜底。

功能源码沿用已完成的 70 项相关 Rust 检查和 56 项相关前端/安装器检查结果。本次只调整版本与说明，并重新构建、校验本地包；不重复功能测试，没有使用真实重置卡。真实兑换、无 Codex 窗口后台、退出/唤醒、更新下载避让和安装升级仍待实机验证。

当前交付目录：`artifacts/release-v0.3.5-unified/packages/`。较早的 `artifacts/release-v0.3.5/packages/` 不含当前全部功能，保留作为历史构建。

Windows 10/11 x64，需要 WebView2 和已登录的可用 Codex CLI。更新签名不等于 Windows Authenticode 签名。
