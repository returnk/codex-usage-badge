# Codex Badge v0.3.5

Opt-in expiring-card automation and a clearer desktop interface.

## Changes

- Add **临期用卡** (expiring-card automation), off by default. Explicit consent authorizes the current account on this computer to attempt eligible free-card redemption within 30 minutes of expiry, including future cards, until disabled.
- Replace the consent message box with a themed card. Show loading feedback, default to Cancel, return to Settings after the decision, and reflect saved authorization before further background checks.
- Preserve antialiased capsule edges, size hover hints to their text, and use the product name CodexBadge in runtime instructions.
- Avoid overlap with the Codex client's update controls during downloading, progress display, and installation.
- Improve quota-recovery handling when service data arrives in stages or card details are incomplete, with bounded follow-up reads.
- Keep card expiry details and the badge dot. Remove the old expiry-notification switch; automation results remain visible in the app even if Windows suppresses a notification.

## Automation behavior

Upgrading does not grant permission. Keep the computer and CodexBadge running; the Codex window need not stay open. Shutdown, sleep, or exiting CodexBadge stops execution. No service or wake task is installed, and launch at login is not enabled automatically.

Existing quota is **not added** to the reset quota. Reset times may change, and successful redemption cannot be undone. Success before expiry is not guaranteed. Do not enable automation for the same account on multiple devices or tools.

Account revalidation, local coordination, and persistent request records protect against duplicate redemption. Disabling stops new requests but cannot guarantee cancellation of one already sent. Uncertain results pause automation and retain the record for review. Unsupported CLI versions are reported as unavailable; there is no private web-API fallback.

## Validation and limits

Automated Rust and frontend checks, local signed-package verification with tamper rejection, and an isolated native WebView preview at 125% scaling passed. Other PCs, mixed-DPI movement, real account authorization/persistence, actual card redemption, and full install/upgrade/restart behavior have not been established by these checks.
