# Codex Badge v0.3.5

Quota handling and local diagnostic improvements. This version is packaged locally and has not been uploaded to GitHub.

## Changes

- Improve quota recovery handling when service responses arrive in stages or include incomplete reset-credit details.
- Add specific local diagnostic reasons and sanitized quota timing information to help explain synchronization results.
- Bound additional quota checks and preserve compatibility with existing settings.

## Validation and limits

39 targeted Rust tests passed for the changed quota handling, account isolation and diagnostics. Rust formatting and diff checks passed. These checks do not establish real reset-event, desktop interaction or installation/upgrade acceptance.

Windows 10/11 x64; requires WebView2, a signed-in Codex desktop app, and a working Codex CLI. Interface: Chinese. This is an independent community project. Updater signatures are separate from Windows Authenticode signing.
