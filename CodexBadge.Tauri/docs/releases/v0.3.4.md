# Codex Badge v0.3.4

Quota synchronization and update reliability improvements, with the existing Glass and System themes.

## Changes

- Recheck older or failed quota readings when opening the hover panel, with throttling to avoid repeated requests. Cached readings now have a subtle dotted underline and an accessible pending-update description.
- Keep update-action errors visible across redraws until a retry is accepted or the update window is reopened.
- Remove the startup entry during uninstall only when it belongs to the installation being removed. Selected app-data cleanup deletes only this Tauri app's files, preserving other CodexBadge data; upgrades continue to preserve settings.
- Expand automated coverage for quota synchronization, frontend behavior, update errors, and installer cleanup. Keep the existing interface and theme choices.
