# 余量 · Codex Badge v0.3.0

**Codex 还剩多少，一眼就知道。**

全新 Tauri 正式发布版本，适用于 Windows 10 / 11 x64。

## 新版亮点

- **额度胶囊**：显示 5 小时剩余，悬停查看本周剩余、重置时间与重置机会。
- **两个主题**：毛玻璃 / 跟随系统，滚轮即可切换；系统主题自动适配明暗。
- **随 Codex 工作**：打开后显示，退出后收起，后台监听下一次打开。
- **独立置顶**：普通模式随 Codex 最小化隐藏；置顶模式继续显示，分别记忆位置。
- **顺手操作**：拖动调整、右键菜单、开机启动；普通模式双击复位。
- **Tauri 2 + Rust**：使用系统 WebView2，无需 .NET Desktop Runtime。

## 使用与更新

余量需要在后台运行，才能自动跟随 Codex；从托盘选择“退出”后，需手动重新启动。

更新、移动便携目录或切换安装方式前，先关闭开机启动，再退出正在运行的版本；到新位置运行后，按需重新开启。从 v0.2.x 升级需重新设置主题与位置。请勿同时运行多个版本。

找不到 CLI 时，可将 `CODEX_BADGE_CLI` 设置为 `codex.exe` 的完整路径。

## 已知问题

- 快速来回悬停可能出现短暂花屏。
- 安装升级、显示缩放、跨屏、反复切换置顶和真实退出重开，仍在持续验证。
- 手动移动胶囊后，详情可能越出侧栏；当前布局可能露出部分“语音”文字。

[反馈问题](https://github.com/returnk/codex-usage-badge/issues/new/choose)时，请注明复现步骤、显示缩放、主题与是否置顶。截图或日志请先检查隐私，不要上传登录凭据。

通过本机 `codex app-server` 只读获取额度，不读取 `auth.json`，不发送模型请求。第三方开源工具，非 OpenAI 官方产品。
