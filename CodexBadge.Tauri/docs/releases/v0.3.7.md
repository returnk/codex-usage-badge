# Codex Badge v0.3.7

历史本地构建记录。当前完整功能已统一至 [v0.3.5](v0.3.5.md)，本页及对应旧包保留原编号。

本地版本，尚未上传 GitHub。

- 新增“临期用卡”：默认关闭，首次明确确认当前账号的持续授权；已开启后，在免费卡到期前 30 分钟内符合条件时自动尝试，无需逐次确认。
- 账号和执行记录保存在本机。使用具体卡 ID 和持久化幂等键，同账号本机互斥；原目标到期前不换下一张。超时先核实，恢复次数受限，无法确认就暂停，避免重复用卡。
- 胶囊驻留且电脑正常运行时，无需打开 Codex 窗口；关机、休眠或退出后不执行。不会启用开机启动、安装服务或唤醒电脑。
- 设置菜单保留开机启动和底部检查更新，“临期用卡”采用右侧打勾。悬停可查看状态、最近结果和时间。
- 移除独立的系统通知开关与旧临期弹窗，保留胶囊红点和卡片到期信息。Windows 通知仅用于自动用卡的成功或需处理失败结果；即使系统未显示，软件内仍能查看结果。
- 包含 v0.3.6 的官方更新下载/安装控件避让修正。

已有额度不与重置后的额度叠加，重置时间可能改变，成功不能撤销。满额、无适用窗口或服务端拒绝时不强制用卡。不保证到期前兑换成功，同账号不要在多台设备或工具同时启用。

关闭阻止新请求，已发出的请求不承诺撤销；先前请求结果无法确认时会保留未决记录并暂停，需要核查官方状态。切换开关不会清空该状态。旧 CLI 不支持时显示不可用，没有内部网页接口兜底。

本次使用离线和模拟 RPC 验证，没有消耗真实重置卡。真实用卡、无 Codex 窗口后台执行、退出/唤醒及安装升级仍待实机验证。

70 项相关 Rust 检查、56 项相关前端/安装器检查通过。最终本地包的哈希、ZIP 内容、EXE 版本/架构、更新签名及篡改拒绝校验通过。最终产物位于 `artifacts/release-v0.3.7/packages-approved/`；其他同版本目录为收尾修正前的候选，不作为本次交付。

Windows 10/11 x64，需要 WebView2 和已登录的可用 Codex CLI。更新签名不等于 Windows Authenticode 签名。
